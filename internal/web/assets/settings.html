Ports

Disabling a port stops charging on it until it is enabled again. Takes effect immediately.

Station

A session ends only after the vehicle has been disconnected this long, since chargers briefly report a disconnect when charging finishes.

Listen address and data directory changes apply after the service restarts.

Display

Hide the clock if the system time is not set correctly.

Chargers (1–4)

Power meters (0–2)

Each meter board has two channels. Assign a channel to a charger to show voltage, current and energy, and to enable dynamic load sharing.

Load sharing

Without load sharing, each port is limited to its own maximum. With it, the system maximum is divided among vehicles that are charging; vehicles that can't be given the minimum wait until power frees up. Dynamic mode lowers the limit on ports drawing less than offered and gives the difference to the others.

Admin password

Saving restarts charger communication; charging continues and sessions in progress are logged and restarted.
